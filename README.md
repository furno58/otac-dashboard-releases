# OTAC Dashboard

Downloads for the **OTAC Dashboard** desktop app (Omega Tactical): the employee dashboard, with a radio push-to-talk key that works in-game and an in-game overlay.

**Download:** [OTAC-Dashboard-Setup.exe](https://github.com/furno58/otac-dashboard-releases/releases/latest/download/OTAC-Dashboard-Setup.exe) (Windows)

The app updates itself automatically. This repository only holds the installer and update files.
